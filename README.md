# Flappy Bird Remake

A browser-based Flappy Bird clone built with vanilla HTML, CSS, and JavaScript using the Canvas API.

## How to Play

1. Open `index.html` in any modern web browser
2. Press **Space**, **Up Arrow**, **click**, or **tap** to flap
3. Navigate through the pipes without hitting them or the ground
4. Try to beat your high score (saved in local storage)

## Features

- Smooth 60fps canvas rendering
- Bird rotation and wing animation
- Procedurally drawn pipes, clouds, and ground
- Score tracking with local storage high score persistence
- Responsive to keyboard, mouse, and touch input
- Start screen and game over screen with restart
